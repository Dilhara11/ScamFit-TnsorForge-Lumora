# Intended impact and limits

The intended users are Sri Lankan fraud analysts and community digital-safety teams reviewing suspicious messages. This prototype provides a trained score, novelty signal and durable review queue to support investigation. It does not verify safety or automatically block accounts.

A possible pilot is one consenting analyst team, with an assumed initial capacity of 100 reviewed reports per week. This is a planning assumption, not measured reach. Measure analyst minutes per report, confirmed useful alerts, benign false alerts, review backlog and delay from the first report to escalation. Compare these with the same team’s manual process before claiming improvement.

The current experiment demonstrates mechanics on a small mixed-source, unreviewed dataset. It does not demonstrate financial loss prevented, real-world accuracy or reduced analyst workload. All held-out messages were routed for review, and the normal false-alert target failed. Sinhala and Tamil performance was weak. A pilot requires source/licence clearance, privacy and label review, independent legitimate controls and stronger language validation before use with people.
